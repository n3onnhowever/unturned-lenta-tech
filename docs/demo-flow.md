# Demo Flow

1. Start backend with `scripts/start-backend.ps1`.
2. Start frontend in backend mode with `scripts/start-frontend-backend.ps1`.
3. Open `http://localhost:3000`.
4. Choose a short shelf video.
5. Click `Запустить распознавание`.
6. Wait until processing completes.
7. Show the summary cards.
8. Show the recognized price tags table.
9. Click `Скачать CSV`.
10. Open the CSV and verify 29 columns.

For a quick frontend-only demo, start `scripts/start-frontend-mock.ps1`.

# Lenta Hackathon Backend Bundle

This folder contains the current best runnable pipeline for backend handoff.

## Contents

- `scripts/` - pipeline code.
- `weights/price_tag_holdout_43_15_neg_e12_best.pt` - honest source-holdout detector used for reported metrics.
- `weights/price_tag_merged_internal_best.pt` - stronger internal detector variant; use only if you intentionally train/evaluate with all available data.
- `sample_outputs/43_15_submission_best_honest.csv` - current best honest CSV sample.
- `reports/43_15_compliance_best_honest.json` - honest GT comparison for the sample CSV.
- `reports/csv_contract_report_43_15.json` - CSV format contract check.
- `requirements_backend.txt` - Python packages required by the final pipeline.

## Install

```powershell
python -m pip install -r requirements_backend.txt
```

## Run On A Video

From this bundle directory:

```powershell
# 1. Extract frames
python scripts/extract_video_frames.py -i path\to\video.mp4 -o work\frames --stride 1

# 2. Detect price tags
python scripts/detect_price_tags_trained.py `
  --weights weights\price_tag_holdout_43_15_neg_e12_best.pt `
  --source work\frames\path_to_video `
  --output work\detect `
  --conf 0.01 `
  --imgsz 1280

# 3. Build hackathon CSV
python scripts/lenta_hackathon_pipeline.py `
  --video path\to\video.mp4 `
  --frames work\frames\path_to_video `
  --detections work\detect\detections.csv `
  --out-csv output\submission.csv `
  --work-dir work\pipeline `
  --engine paddle `
  --no-dedupe
```

To enable super-resolution upscale before OCR, pass a local OpenCV DNN super-resolution model:

```powershell
python scripts/lenta_hackathon_pipeline.py `
  --video path\to\video.mp4 `
  --frames work\frames\path_to_video `
  --detections work\detect\detections.csv `
  --out-csv output\submission.csv `
  --work-dir work\pipeline `
  --engine paddle `
  --upscale-model weights\EDSR_x4.pb `
  --upscale-model-name edsr `
  --upscale-scale 4
```

The exact frames subfolder name is generated by `extract_video_frames.py` from the input path. For nested paths it joins parent folders and the video stem with `_`.
